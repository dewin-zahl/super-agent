# super-agent

本地部署的 dsh-superagent 工作仓库：agent 账号 `dewin-max-b` 在这里接工单、开分支、提 PR。

## 怎么发起工作

在 issue 里（或任意 issue / PR 的评论里）@ 它：

```
@dewin-max-b 把下面这句说明改成一句话：本仓库用于演示 dsh-superagent 的工作流
```

约 1 分钟内 Superagent 概览页会出现一个工单；agent 在自己的 worktree 里改完，
回到原会话回复，必要时发 PR。
